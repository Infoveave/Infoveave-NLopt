# WIF-011 — Managed wrapper evidence

## Implementation

- Public API matches the WIF-010 contract and contains no What-If domain concepts.
- Native calls use the pinned C ABI and cdecl callbacks.
- A `SafeHandle` owns each optimizer. Explicit disposal is idempotent; running disposal and concurrent configuration are rejected.
- Callback userdata weakly references its optimizer, while the optimizer owns callback delegates for the full native call. A finalizer test proves an undisposed optimizer is not permanently rooted.
- Managed callback exceptions are captured, force-stop is requested on the callback thread, and the original exception is rethrown only after `nlopt_optimize` unwinds.
- Cancellation and `RequestStop` set managed flags; the next callback invokes `nlopt_force_stop`. Cancellation does not dispose the handle.
- Native resolution accepts only the copied `nlopt/` runtime directory for the current RID, compatibility `1`, NLopt `2.11.0`, pinned source provenance, and matching native file hash. There is no system-library fallback.
