## Native ABI

- ABI: C with cdecl calling convention on all supported targets.
- `nlopt_opt` is an opaque pointer created by `nlopt_create` and destroyed by `nlopt_destroy`.
- Dimensions and callback counts use C `unsigned` and map to managed `uint` at the interop boundary.
- Values, objectives, gradients, bounds, tolerances, and steps use C `double`.
- Objective/inequality callback: `double callback(unsigned n, const double* x, double* gradient, void* data)`.
- Inequality convention: `g(x) <= 0`.
- Native filenames are verified from install output: `libnlopt.so`, `nlopt.dll`, `libnlopt.dylib`.

## Callback, cancellation, and lifetime rules

- Native delegates and callback state remain strongly reachable until `nlopt_optimize` returns.
- A callback catches every managed exception, captures the first with `ExceptionDispatchInfo`, requests `nlopt_force_stop` from that same callback/native thread, and returns `double.NaN`.
- `Optimize` rethrows the original captured exception after native frames unwind.
- Cancellation and `RequestStop` set an atomic flag. The next objective or constraint callback calls `nlopt_force_stop`; neither action disposes the native handle.
- Separate optimizer instances and callback state support simultaneous callers.
- A second operation or configuration call on a running instance throws `InvalidOperationException`.
- `Dispose` while running throws `InvalidOperationException`; otherwise the safe handle is released exactly once.
- Raw native outcomes, including limit and roundoff codes, are preserved without application-level interpretation.
