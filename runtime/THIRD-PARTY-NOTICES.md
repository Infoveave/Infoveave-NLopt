# Third-party notices

The `Infoveave.NLopt` NuGet package contains no native NLopt binaries or copied NLopt source.

Separately published runtime bundles contain NLopt 2.11.0 built without Luksan and C++ sources. Each runtime ZIP carries the complete notices copied from the exact pinned source archive in its own `nlopt/THIRD-PARTY-NOTICES.md` file, along with source and build provenance in `nlopt/manifest.json`.
